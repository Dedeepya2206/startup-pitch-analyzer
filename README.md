# Startup Pitch Analyzer 

## Overview
Startup Pitch Analyzer is a web-based application that analyzes startup ideas and provides feedback to improve pitch quality.

## Features
- AI-based pitch analysis
- Section detection (Problem, Solution, Market, etc.)
- AOA, MOA, IR, PVB evaluation
- Score calculation
- Suggestions & investor questions
- PDF report generation

## Technologies Used
- Python, Flask
- HTML, CSS, JavaScript
- NLTK, Scikit-learn
- JSON (Database)

## How to Run
1. Clone the repository
2. Install requirements:
   pip install -r requirements.txt
3. Run the app:
   python app.py
4. Open http://127.0.0.1:5000

## Use Case
Helps students and startup founders create investor-ready pitches.
